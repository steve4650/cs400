# jar

Java archive. whole app in a file!

`jar -cfe calculator.jar HelloWorld *.class` - here, `HelloWorld` is where `main` is.

`javac -cp junit5.jar:. HelloWorld.java` - include stuff from the jar and classes in the directory `.`

See slides. You can compile in a jar into another java file or run a specific class from it directly.

`java -jar junit5.jar -cp . -c BinarySearchTree`

# tests

## categories

- unit: tests single unit (class method)
- integration: tests unit interactions
- black box: only tests through public interfaces
- property: tests partcular properties are held
- and much much more!

## axes

1. unit vs integration
1. opaque vs clear (public interfaces vs details)
1. I/O vs properties

test at scale that makes sense. e.g. opaque tests are more robust long term but to test BST rotation you need details (Clear testing).
