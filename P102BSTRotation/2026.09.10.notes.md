# jar

Java archive. whole app in a file!

`jar -cfe calculator.jar HelloWorld *.class` - here, `HelloWorld` is where `main` is.

`javac -cp junit5.jar:. HelloWorld.java` - include stuff from the jar and classes in the directory `.`

See slides. You can compile in a jar into another java file or run a specific class from it directly.

`java -jar junit5.jar -cp . -c BinarySearchTree`
