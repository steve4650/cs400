## binary search tree

- tree: one root node with 2 parents. everybody else has exactly 1 parent.
- binary: all nodes <= 2 children.
- search: all values to left of current node are smaller, all values to right are larger. no duplicates.

it's easy to search down a tree. just start at the root, go left or right.

## traversing a binary search tree

- in order: left, node, right (recursively)
- pre-order: node, left, right (recursively)
- post-order: left, right, node (recursively)
- level-order: go down levels, read nodes left to right

## heights of a binary search tree

2 types

- edge height: start at 0
- node height: start at 1 (empty is 0) ** we will use this in this course **

```
height(tree) = max(height(node))
```

## searching in a binary search tree

`O(Height)` operation. (unbalanced, doesn't scale with N = # of nodes yet)

## inserting in a binary search tree

- search for the value.
  - if found, return early
- add in proper child location (left or right of appropriate node)

`O(Height)` operation. (unbalanced, doesn't scale with N = # of nodes yet)

## deleting in a binary search tree

- delete leaf. just kill, remove pointers.
- deleting with one child. find child, promote to parent.
- delete with two children.
  - find max values below the node. (predecessor)
  - promote predecessor
  - recursively delete the predecessor.

  alternatively, you can find the max value below the node (successor)

`O(Height)` operation. (unbalanced, doesn't scale with N = # of nodes yet)
