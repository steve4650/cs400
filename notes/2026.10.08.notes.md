## counting sort

- loop through sequence of digits (7, 8, 8, 0, 1)
- count how many of each digit there are
- count up and keep running count of how many items you've sorted in

so like if there's a known finite alphabet of size A, then this is ,...

### complexity

- n - number of data
- r - range of symbols
- q - length of each data (in symbols)

Time: O(n) (count number of occurrences, then do a sort pass)
Space: O(2r+n)
