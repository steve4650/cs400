# graphs

model lots of things. social networks. HTML links.

- defined as a pair of sets. set of nodes (V) and set of edges (E)
- edges are typically pairs of nodes (u, v) where u, v ∈ V. either an ordered tuple (u, v) for directed graphs or an unordered pair {u, v} for undirected graphs.
  - note: can be more than one edge between the same pair of nodes

## nodes

- neighbors
- degree of node
- data aka value

## edges

- weighted edge: has value/cost associated with it
- directed edge: order of pair matters
- undirected edge: order of pair does not matter
- bidirectional edge: equivalent to 2 directed edges (or one undirected edge)
- self-loop

## more definitions

- paths
  - cost: sum of weights along both
  - cycle: first and last node is same
- subgraphs
  - subset of nodes/edges (where edges are along among nodes in the subset)
- directed/undirected graphs
- weighted/unweighted
- cyclic/acyclic (are there any cycles?)
- connected/disconnected (is there a pair of nodes between any path?)
  - note: take directedness into account. sometimes are connected as undigraph but not connected as digraph (weakly connected)

# graph implementations

- adjacency list
  - for each node, maintain a list of target nodes
  - space: O(V + E)
- adjacency matrix
  - V x V boolean matrix (T/F whether not A connects to B)
  - space: O(V^2)
  - note: undirected graphs have symmetric adjacency matrix (A = A^t)

## depth first

- assume all nodes unvisited
- DFT(v):
  - mark v as visited
  - foreach unvisited neighbor u of v:
    - DFT(u)

list complexity: O(E*V)
matrix complexity: O(V^2)

## breadth first

- assume all nodes unvisited
- BFT(v)
  - create queue q
  - mark v as visited
  - enqueue v
  - while q is not empty:
    - dequeue node w
    - foreach neighbor u of w:
      - if u visited: do nothing
      - else: mark u as visited and enqueue u

Prim's Algo:
- assume all nodes unvisited
- prim(v)
  - create minimum priority queue q
  - insert all edges of v into q, mark v as visited
  - while q not empty:
    - remove min edge {w,u} from q
    - if u has not been visited:
      - add u to spanning tree
      - add all edges of u in to q and mark u as visited
